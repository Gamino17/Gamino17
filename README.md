# Daniel Gamino

**Dirección técnica en [LDA Homes](https://ldahomes.com) · Software, integraciones e IA aplicada**

Trabajo con empresas para convertir necesidades de negocio en aplicaciones e integraciones que puedan usar, mantener y evolucionar. Combino dirección técnica, desarrollo asistido por IA y revisión humana, con atención a la seguridad y la continuidad del servicio.

### En qué trabajo

- **Software para operaciones:** aplicaciones internas, APIs e integración entre sistemas.
- **IA aplicada:** agentes y automatización de procesos, con permisos definidos y resultados revisables.
- **Entrega y mantenimiento:** pruebas, revisión de código, documentación y preparación de despliegues y recuperación.

### Proyecto público

[**AMI · Agent Mobile Identity Protocol**](https://github.com/Gamino17/AMI) explora identidad móvil y permisos para agentes de IA, con interfaces MCP y REST. El repositorio incluye código, documentación y ejemplos de integración.

### Cómo trabajo

Primero entender el negocio y revisar lo que existe; después, acordar prioridades y criterios de aceptación. Desarrollo en entregas pequeñas, con revisión y demostraciones para comprobar el resultado antes de avanzar.

Parte de mi trabajo se desarrolla en repositorios privados de clientes. Este perfil reúne los proyectos y materiales que puedo compartir públicamente.
